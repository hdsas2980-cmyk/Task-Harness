# 独立看板使用说明

版本标识：看板 UI 2026.09.12-r2

这是独立 WebUI，不是 Tauri/WPF 程序，不需要旧版 EXE。运行需要 Python 3.10+ 和浏览器；不需要安装 Node.js、pytest 或 Codex skill。

## 解压与启动

完整解压 ZIP，保留 TaskBoard 下的全部目录和文件。双击 start.bat；或者在解压后的 TaskBoard 目录运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\start.ps1 -NoPrompt
```

控制台显示前端、后端、上次路径和当前路径；浏览器打开打印的本机地址。默认端口被占用会选择其他空闲端口，因此请以本次控制台地址为准，不要继续使用旧书签或旧 EXE。

双击 BAT 时可输入目录，回车复用上次路径，输入 s 则到页面选择会话。不要直接双击 HTML。

## 载入任务

- 点击页面“载入任务”或按 L，先打开会话面板，自动读取本机 Codex 会话。
- 可以搜索会话标题、路径、编号，再点击会话行切换任务目录。
- 也可以在面板上方手动输入项目根或 .harness 绝对路径；只有“浏览目录”才打开系统目录窗口。
- 会话根优先取 CODEX_SESSIONS_DIR，其次 CODEX_HOME/sessions，最后是用户默认 .codex/sessions。
- 读取失败时在面板内显示原因，点击“刷新会话”重试。关闭按钮、遮罩、Esc 均可关闭面板，不需要等待请求完成。

页面底栏应显示本说明开头的版本标识。如点击“载入任务”直接出现文件窗口，或找不到“从 Codex 会话中选择”，请核对当前地址是否属于本次启动的程序。

## 历史原版还原

本包按历史会话中 r2 界面补丁及后续“轨迹跟随当前行 / 日志优化”补丁恢复，不使用上一轮重新设计的卡片。

- 保留“任务列表 / 任务轨迹 / 进度日志”三个标签。
- 组内卡片网格、间距、配色、边框和抽屉样式沿用历史原样；阶段标题增加下述折叠按钮。
- 卡底是四段状态条、审计简报、“证据 N · 评审 N ↗”按钮、“任务轨迹 →”链接。
- 轨迹是当前快照卡与证据评审时间轴，无任务下拉框；日志恢复概览、最近 8 行和折叠原文。
- 载入面板恢复原顺序：指定任务目录在上，会话选择在下。读取会话、请求中可关闭、失败重试的修复保留。

界面沿用历史 r2 标识，不用新增版本横条改变版式。具体交付文件以 manifest.json 内的 SHA-256 核验；旧副本可能也显示 r2，不能只凭标签判断文件一致。

## 任务内容与只读边界

项目必须有 .harness/harness.db。旧 tasks.json / evidence.jsonl / reviews.jsonl / progress.txt 不是活数据；请先用转换脚本一次性导入。人类可读字段必须由任务生成方直接写中文；保留 ID、机器枚举、路径、命令和原始输出，不使用翻译文件或 _zh 旁路字段。

服务端复用包内 harness_db.py 与 scripts/check_task_harness_language.py。没有数据库或契约不合格会指出错误，不自动翻译、不写任务状态、不回退 JSON。证据和评审可为空，但不能视为已经执行。

会话列表仅用于定位目录。看板不改会话记录，不将聊天内容作为任务证据。原始测试通过不等于独立评审通过。

## 更新与识别

关闭自己启动的旧服务，再从新解压目录启动，并使用新控制台打印的地址。不要将新 HTML/JS 单独覆盖到旧服务目录，不要删掉 scripts 子目录。

manifest.json 保存本包程序文件的 SHA-256，可用来核对资源。运行可能产生 .last-source 和 __pycache__；它们是本地运行文件，不是随包交付的任务数据。

本包已纳入真实 HTTP 会话加载与模拟 DOM 按钮链路测试。模拟 DOM 不代表真实浏览器视觉验收。

## 本次布局调整

- **阶段分组**：默认全部折叠，点击标题展开；展开另一阶段会收起前一个，再次点击可全部收起。轮询保留展开状态，切换任务来源后恢复折叠。键盘切换当前行时展开其所在阶段，阶段折叠本身不改变当前行。
- **键盘说明**：移至顶部“键盘操作”展开面板；左下不再占位，当前行详情向下延伸。
- **已通过**：左上增加数量与筛选，直接按任务的 `passed` 状态统计，不将待评审算作通过。

其余历史卡片、证据评审抽屉、任务轨迹和进度日志布局保持不变。
