## 还原内容

- CSS 以历史原样为基线；仅追加下述用户批准的折叠、顶部键盘说明与已通过筛选样式，其他主题、尺寸和卡片布局不再设计。
- 卡片恢复阶段标题与比例条、组内网格、描述、依赖、原因、四段状态条、审计简报，以及统一审计按钮和轨迹链接。
- 轨迹恢复“当前快照卡 + 审计时间轴”；跟随当前行，只关联证据与评审，叙事日志留在进度日志标签。
- 进度日志恢复概览、最近 8 条非空原始行、标签、来源行号与折叠原文。
- 载入面板恢复历史顺序：目录输入在上，会话选择在下。

[历史指纹清单](tests/history-design.json)固定完整原始 HTML、CSS 与卡片、状态条、轨迹渲染函数的 SHA-256。测试不从当前待测代码重新生成期望值，测试先按 `tests/layout-adjustments.json` 精确撤销本次批准的三处调整，再去除前述两种错误/扫描消息节点，与原指纹比对；不重写历史哈希，其他自行改版仍会触发失败。

## 明确保留的非设计修复

这不是整份程序逐字回滚，以下已确认修复保留，但不重做布局：

1. 服务端与独立包继续使用同一份技能中文契约检查器；保留 JSON 键、ID、枚举、路径、命令与原始输出，不恢复翻译文件或 `_zh`。
2. 默认验证摘要取原字段 `summary`，原始 `tests` 留在历史折叠详情中；技术字段“revision”的界面标签使用中文。
3. 载入立即打开，扫描不等待轮询队列；保留请求序号、错误显示、重试、关闭与来源切换修复。会话根查找支持环境变量与默认目录，只有“浏览”打开系统目录框。
4. 页面仅增加一个默认隐藏的契约报错节点，以及会话扫描消息节点；没有新增 CSS 或版本横条。
5. JSONL 来源行号取物理行；日志保留空行后的真实行号，退出信号取最后一次记录；选中任务在刷新后按 ID 保持。
6. 已移除的复制按钮不再无条件绑定，避免脚本启动失败。不恢复旧版直读文件的旁路函数。

## 用户批准的三处后续调整

- 阶段默认全部折叠，同一时刻最多展开一个阶段，再次点击可收起；阶段操作不改变当前行。轮询保留展开状态，切换来源重新折叠，键盘移动当前行时展开所在阶段。
- 键盘操作说明从左下移至顶部“键盘操作”展开面板，原侧栏当前行详情使用释放的空间。
- 左上补充“已通过”的真实数量和筛选，状态枚举仍为 `passed`。

以上是历史恢复之后用户明确要求的差异，不改变卡片底部、审计抽屉、轨迹和日志设计。
